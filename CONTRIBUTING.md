# Contributing

Thanks for your interest in Palwyn.

## What's welcome

- **Bug reports**: open an [issue](https://github.com/maeldotdev/palwyn/issues). Say which phone and Android version, which Windows version, what you did, what you expected and what happened.
- **Ideas and feature requests**: open an issue, or start a [discussion](https://github.com/maeldotdev/palwyn/discussions) for questions and open-ended ideas.
- **Security problems**: never in a public issue. See [SECURITY.md](SECURITY.md).

## Code contributions

Palwyn doesn't accept pull requests for now; all code is written by the maintainer. This may change later, and this file will say how when it does. Pull requests opened in the meantime will be closed, but an issue describing the same fix or idea is very welcome.

You're free to fork the code under the terms of the [GPL-3.0](LICENSE), with a different name (see [TRADEMARKS.md](TRADEMARKS.md)).
